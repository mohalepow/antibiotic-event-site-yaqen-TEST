# 💊 موقع فعالية المضادات الحيوية

طوّرت هذا الموقع ليكون واجهة تفاعلية لفعالية التوعية بالمضادات الحيوية التابعة لنادي يقن في كلية الصيدلة بجامعة أم القرى.

حاولت أقدم تجربة ممتعة ومختلفة تجمع بين التوعية والتفاعل، بحيث نقدر نوصل المعلومات بطريقة بسيطة ومبتكرة.

الموقع قابل للتطوير بشكل كبير، وفيه مجال نضيف ألعاب وأفكار وميزات جديدة، ونحسّن التصميم والتجربة أكثر وأكثر. هذي مجرد البداية، والقادم بإذن الله أفضل!

**المبرمج:** [@dr0ghost](https://x.com/dr0ghost)


## تحديث لوحة الكوميك الجماعية

قبل نشر النسخة المحدّثة، افتح Supabase ثم SQL Editor وشغّل الملف `supabase-unique-participants.sql` مرة واحدة. يضيف هذا الملف تسجيلًا مركزيًا لأسماء المشاركين ويمنع تكرار الاسم حتى عند استخدام أجهزة مختلفة. بعد ذلك انشر ملفات الموقع كما هي؛ صورة الكوميك الأصلية موجودة في `assets/community-comic.png`.

أصبحت لوحة الكوميك مكوّنة من ١٢٠ مربعًا، ويكشف كل مشارك مربعًا واحدًا فقط من الصورة الأصلية.

## رفع السعة إلى ١٢٠ مشاركًا
شغّل `supabase-capacity-120.sql` مرة واحدة في Supabase SQL Editor. أصبحت لوحة الكوميك ١٢٠ مربعًا (١٢ عمودًا × ١٠ صفوف)، ويُمنع تسجيل مشارك رقم ١٢١ حتى حذف تسجيل سابق.

## حذف مشارك وفتح اسمه ومربعه
افتح `delete-participant-by-name.sql`، واستبدل `اكتب اسم المشارك هنا` بالاسم المطلوب في الموضعين، ثم شغّل الاستعلام في Supabase SQL Editor. هذا يحذف تسجيل الاسم ومربع الكوميك الخاص به، فيصبح الاسم والمربع متاحين من جديد. لا يحذف نتائج اللاعب من لوحة المتصدرين.


## التحكم في إيقاف الموقع مؤقتًا

لتفعيل ميزة إيقاف دخول الزوار وعرض رسالة مخصصة أو مؤقت للفتح التلقائي، شغّل ملف `supabase-site-access-control.sql` مرة واحدة من Supabase → SQL Editor. بعد ذلك سجّل الدخول إلى لوحة التحكم، واستخدم قسم «التحكم في إتاحة الموقع». اكتب رسالة الزوار، ويمكنك تحديد وقت فتح تلقائي اختياري، ثم اضغط «إيقاف دخول الزوار». لإعادة فتح الموقع قبل الموعد اضغط «فتح الموقع الآن».
